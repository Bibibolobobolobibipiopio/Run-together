# run together groupe 10 giordanino silvestre

## Contenu des fichiers :

### Dossier CSV
Le dossier csv regroupe tous les fichiers utilisés pour peupler les tables. Nous les avons généré avec l'outil [mockaroo](https://www.mockaroo.com/)

### ```creer_tables.sql```
Permet de créer toutes les tables nécessaires à la base de données utilisée pour notre projet

### ```charger_csv.sql```
Permet de peupler les tables grâce aux données présentes dans les fichiers csv

### ``requetes.sql``
Contient les différents types de requêtes demandées dans le sujet et qui pourraient être utilisée dans l'application

### ``recommandation.sql``
Comporte quelques requêtes sur des exemples de recommandation (ce que l'application pourrait recommander à l'utilisateur) ainsi que les recommandation de critères pour l'indice de recommandation de défis
